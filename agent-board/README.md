# Agent Board

Показывает, кто из агентов работает, кто ждёт ответа и что нужно переслать. Стиль Windows 98, работает на ПК (окно + уведомления Windows) и на телефоне по Wi-Fi.

Агенты не подключаются к приложению напрямую: они кладут маленький JSON-файл (маркер) в папку, Agent Board его забирает. Новый агент появляется в списке сам после первого маркера.

## Установка (Windows)

Нужен Python 3.10+ в PATH.

```powershell
cd agent-board
powershell -ExecutionPolicy Bypass -File install.ps1
```

Установщик скачает 98.css и иконки Windows 98 (в репозитории их нет), создаст ярлык «Agent Board» на рабочем столе и в автозагрузке (сервер стартует в фоне при входе в Windows). Окно открывается в Microsoft Edge в режиме приложения. При первом запуске Windows спросит про брандмауэр — разрешите Python для **частной** сети, иначе телефон не подключится.

Данные хранятся в `%USERPROFILE%\AgentBoard`: `config.json`, `state.json`, папка `markers`.

## Маркер

Файл `*.json` в папке `%USERPROFILE%\AgentBoard\markers` (или в другой папке из «Файл → Папки с маркерами»):

```json
{"project": "AZS", "agent": "Opus (1)", "state": "done", "task": "Ревью PR #42", "to": "Codex", "note": "2 замечания", "result": "D:\\AZS\\reviews\\pr42.md"}
```

| state | что значит | что делает Agent Board |
|---|---|---|
| `working` | начал задачу | закрывает напоминание «ждёт ответа» |
| `waiting` | ждёт ответа владельца | напоминание + уведомление |
| `done` | закончил | уведомление; если указан `to` — напоминание «Переслать `to`» |
| `blocked` | застрял | напоминание + уведомление |
| `idle` | свободен | — |

Если `working` не обновлялся дольше 90 минут, агент помечается «нет вестей» (настраивается `stale_minutes` в `config.json`). Нечитаемые маркеры через 10 секунд переносятся в `markers\bad` с описанием ошибки.

Готовый текст для агентов: «Справка → Инструкция для агентов» (кнопка «Копировать»).

## Телефон

«Файл → Подключить телефон» показывает ссылку с ключом доступа. Без ключа с других устройств сервер отвечает 403. На телефоне звук и вибрация при новых напоминаниях (коснитесь страницы один раз, чтобы браузер разрешил звук).

## Запуск без установки

```bash
python fetch_assets.py
python server.py        # http://127.0.0.1:8098/
```
