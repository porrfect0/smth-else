# SSJ VPN

Установка VPN на два сервера с общей подпиской для **Happ** и **V2RayTun**.

| Сервер | Что ставится | Имя в подписке |
|---|---|---|
| `2.26.55.113` | VLESS + Reality + Vision (TCP 443) — один протокол | **Gemini** |
| `201.8.94.161` | 1. VLESS + Reality + Vision (TCP 443)<br>2. VLESS + Reality + XHTTP (тот же 443, через fallback)<br>3. VLESS + Reality + XHTTP packet-up (TCP 8443, резерв) | SSJ VPN · Vision / XHTTP / Reserve |

Подписка `SSJ VPN` раздаётся с `2.26.55.113` на порту `2096`.

## Почему так (стабильность)

- Только Xray-core, без панелей и Docker: на `201.8.94.161` занимает ~30 МБ (geo-базы не ставятся, journald ограничен 30 МБ).
- Reality без домена и сертификатов: нечему протухать.
- gRPC и Trojan не используются: в Xray 26 они помечены как устаревшие и могут пропасть при обновлении.
- systemd `Restart=always`, BBR, TCP keepalive, MTU probing.
- Повторный запуск `deploy.sh` не меняет ключи, UUID и ссылку подписки: клиентам ничего перенастраивать не нужно.

## Установка

Нужен доступ `ssh root@<ip>` по ключу к обоим серверам (Debian/Ubuntu с systemd). Порты 443 и 8443, а на первом сервере ещё и 2096, должны быть свободны.

```bash
git clone <этот репозиторий> && cd <репозиторий>
# при необходимости поправьте ssj.conf (имена, SNI, SSH-порт)
./deploy.sh
```

В конце скрипт выведет ссылку вида `http://2.26.55.113:2096/<токен>`. Добавьте её в Happ или V2RayTun через «+» → «Добавить подписку» (или из буфера обмена).

Если у провайдера включён внешний файрвол (security group), откройте в нём TCP 443, 8443 и 2096. `ufw`, если он включён, скрипт настроит сам.

## Обслуживание

- Обновить Xray или применить изменения из `ssj.conf`: снова запустить `./deploy.sh`.
- Закрепить версию Xray: `XRAY_VERSION="v26.11.9"` в `ssj.conf`.
- Сменить все ключи: удалить `/usr/local/etc/ssj/state.env` на сервере и запустить `./deploy.sh`. Подписка в приложениях обновится сама (интервал 12 ч или вручную).
- Логи: `journalctl -u xray -e`, `journalctl -u ssj-sub -e`.

Токен в ссылке подписки — единственная защита (HTTP без домена). Не публикуйте ссылку.
